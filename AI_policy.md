# Policy on use of artificial intelligence (AI) tools

Use of AI tools such as ChatGPT or Claude is not prohibited in this workshop. However, the focus is on learning the fundamentals of computer programming, and having AI write code for you will not advance your understanding. AI should be used only as a learning aid. Work through the code relying on your own thinking, and consult AI only when you need help understanding something.

## Good uses

- Asking what a line of code, a function, or an error message means
- Asking for a concept to be explained in a different way
- Asking why your code isn't working, **after** you have tried to figure it out yourself

## Not what we're here for

- Pasting in an exercise and running the code it gives back
- Having AI generate boilerplate or starter code for you

## Check everything

AI still makes mistakes, and it can sound confident when it is wrong. Test and validate anything you get from it, and make sure you understand it before you use it.

## Protect your data

Do not paste patient data or unpublished data into AI tools. The example data used in this workshop is synthetic and is fine to use.

## Why this matters

Struggling with a problem and finally getting it to work is where most of the learning happens. If an AI tool does that part for you, the code may run, but you will not be any better prepared for the next problem, which will not come with a solution attached.
